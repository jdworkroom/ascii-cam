# ASCII CAM

실시간 ASCII 아트 카메라. 두 컷 프레임: 위 칸은 흑백 사진, 아래 칸은 글자로 그린 인물.

- ASCII 모드: 문자 범위 전환 — 기본(`. - * #`) / 코드 / 영문 / 한글 자모 / 숫자. 글자별 획 양을 재서 밝기 순 자동 정렬, 검은 배경
- EMOJI 모드: 칸 색에 가장 가까운 사물 이모지(🍎🍊🍋🥦🫐🍇…)로 그리기
- 인물만: MediaPipe Selfie Segmenter로 사람만 글자/이모지로 그리고 배경은 검게 (불러오지 못하면 전체 화면)
- 전면/후면 카메라 전환, 아래 칸 배경색 선택(밝은 배경이면 글자 검정)
- 설정 시트: 표현(문자/이모지) · 문자 범위 · 배경색 · 크기 · 대비
- 아래 칸 탭: 글자 종류 순환 (기본 → 코드 → 영문 → 한글 → 숫자 → 이모지)
- 복사 버튼: 지금 화면을 텍스트(문자/이모지)로 클립보드에 복사
- 글자 크기(ASCII 6~80, 기본 37) · 대비 슬라이더
- 촬영 버튼: PNG 저장 / 공유
